## 🔗 LINK STANDARDIZATION RULES

### Rule 1: Always use RELATIVE paths
```markdown
❌ WRONG:  /Users/ninanitzsche/.claude/projects/.../memory/MEMORY.md
✅ RIGHT:  ../../MEMORY.md (from docs/config/)
✅ RIGHT:  ../MEMORY.md (from root/)
```

### Rule 2: Root reference style
```markdown
❌ WRONG:  [Link](./docs/database/database-guide.md)
✅ RIGHT:  [Database Guide](docs/database/database-guide.md)
✅ RIGHT:  [Link](docs/database/database-guide.md#section-name)
```

### Rule 3: Consistent anchor names
```markdown
✅ USE: ## 🎯 Title Format
✅ LINK: [Description](#-title-format)
```

### Rule 4: Index all documents
- Every folder must have `README.md` or be listed in parent
- Every referenced file must exist
- Dead links = broken onboarding
