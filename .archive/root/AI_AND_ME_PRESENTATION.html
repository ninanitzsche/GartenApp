🔧 Service Layer: Das Pattern

Sprint 1 schreibt plantService.ts (100 Zeilen):

async function fetchAll(filters?) {
  try {
    let query = supabase.from('plants').select('*');
    if (user?.id) query = query.eq('user_id', user.id);
    return await query;
  } catch (error) { throw error; }
}

Sprint 2-5: Gleiches Pattern für shoppingService, photoService, taskService...

Resultat: 70% Code-Reuse! Nicht neu schreiben, nur kopieren!

🐛 Top Gotchas (und Lösungen)

  • 🚨RLS Policies: User-ID in WHERE clause vergessen → Sicherheitsloch!
  • 📸Image Upload Web: Native = file://, Web = blob:// URIs
  • 🔄useEffect Infinite Loop: Dependencies vergessen
  • 📱FlatList Performance: Braucht key props + optimization
  • 🔐Type-Safe Navigation: Types nicht synchron = Runtime Errors

Alle diese Gotchas sind in MEMORY.md + docs/LEARNINGS dokumentiert!
